About

I'm Mina Sareany, a front-end developer from Egypt. I like interfaces that open instantly, look sharp on a phone, and don't make people think about how to use them.

I build with HTML, CSS and JavaScript first, reach for React when an app needs real state, and ship as a PWA so it installs like a native app and still works when the connection drops. The three projects above are mine end to end — design, build, deploy.
